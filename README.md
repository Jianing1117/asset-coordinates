A 股、美股、债券、黄金、加密资产五类资产现在各自站在历史的什么位置。只判断位置，再把用户自己定的规则算给他看，不预测涨跌。参考站是 research.charlespai.com，方法与文章来自 Long Arc「投资配置」这条线。

## 位置分怎么算

每个市场一个 0 到 100 的位置分，越高越贵或越热。各分项先换成 0 到 100 的历史分位（每个时点只和当时已发生的历史比），按权重合成，取 5 日平均后分五档：低位区、偏低、中性、偏高、高位区（每 20 分一档）。

| 市场 | 分项与权重 |
| --- | --- |
| A 股 | 中证全指市盈率分位 40%，股债性价比分位（反向）40%，情绪温度 20% |
| 美股 | 席勒市盈率分位 50%，超额盈利收益率分位（反向）30%，VIX 平静度 20% |
| 债券 | 中债 10 年期收益率分位（反向）50%，美债 10 年期收益率分位（反向）50% |
| 黄金 | 实际金价分位 50%，相对 200 周均线偏离的分位 50% |
| 加密 | ahr999 分位 40%，MVRV 分位 40%，恐惧贪婪指数 20% |

位置分只负责显示。规则另看三种状态：低位、中间、高位。位置分低于 20 进入低位、回到 23 离开；高于 80 进入高位、回到 77 离开。比特币的低位改用明确条件：MVRV 低于 1，或价格跌破 200 周均线。

## 规则怎么动仓位（2026-11-13 按评审改过）

第一版是五档都调仓，评审后发现有硬伤：美股、债券、黄金的位置分常年偏高，按它调等于长期少配；A 股换档太勤，中间几档没有区分力；幅度没有上限；ahr999 的拟合参数已经漂移。现在的规则：

| 市场 | 规则 |
| --- | --- |
| A 股 | 只在两端动：低位上调，高位下调，中间不动 |
| 美股、黄金 | 不调到基准以下。偏高时只管新增资金，高出基准的卖回基准。美股的加仓由回撤阶梯决定，见下 |
| 债券 | 比例不变，只给期限倾向。中债、美债各有一个位置分，不合并 |
| 比特币 | 偏冷时补到基准，不额外加码；高位下调。ahr999 退出位置分，只留参考图 |

美股回撤阶梯（2026-11-13 加入）：距标普 500 历史最高收盘价跌破 15%、20%、30% 各算一档。档位按这一轮跌到过的最深处算，每档一轮只触发一次，创新高后整轮重置。每多一档，规则仓位上调上限的三分之一。阶梯状态在 `us.json` 和 `summary.json` 的 `rule.ladder` 里（level、peak、deepest、triggers、next）。每多跌破一档，`sinceLastRun` 里会多一条，即使规则状态本来就是「低位」。这条提醒路径只用模拟数据看过页面，脚本里的事件输出还没有被真实行情触发过。

单次调整不超过基准的两成，也不超过 5 个百分点；A 股和美股合计上调不超过 5 个百分点。「每档幅度」的选项已去掉。计算在 `app.js` 的 `plan()`，状态在脚本的 `buildScore()`。基准比例存在用户浏览器的 localStorage（键名 `lac-profile`），不上传。

比特币位置分现在是：MVRV 分位 50%，相对 200 周均线的分位 30%，恐惧贪婪指数 20%。债券位置分是中债 10 年期收益率分位取反，美债另出一个。上面表格里这两行以此为准。

## 给 Codex：每日更新要做的事

1. 北京时间每天 07:00 和 19:00 各运行一次 `npm run update`。使用 `~/.local/share/asset-coordinates/` 的独立运行副本。
2. 看退出码：0 是全部成功；2 是有数据源失败、已沿用缓存（页面会标「数据停在某日」）。连续几天都是 2 再处理。
3. 看 `site/data/summary.json` 的 `sinceLastRun`：非空表示有市场的规则状态变了（低位、中间、高位之间），这是唯一需要提醒用户的事件。位置分的五档标签变化不提醒。近十年各市场平均每年变化 0.5 到 2.8 次。
4. 只提交并推送更新后的 `site/data/`，由 Vercel 自动发布到正式子域名。
5. 定时任务属于「新建自动化」，建之前要先问用户，并在 System Log 里记一条。

后台任务读不到 `~/Documents`。定时任务要么在能读到的位置跑一份副本，要么先确认运行环境的权限。本地预览服务遇到过同样的问题。

## 要注意的

- 视觉遵照「加宁慢慢来」Brand Kit。每次做视觉改动前重读正本。五个市场一项一色，顺序固定：天蓝、樱粉、丁香紫、薄荷绿、黄油黄。图表默认灰，只强调一条线，不用双纵轴。
- Brand Kit 的网页样板里没有「数据看板」这一种页面。本站是在样板的索引行、窄栏加宽栏结构上补了位置条、读数和图表容器。用户满意后可以存回 Brand Kit 作样板。
- 文案语气照 Brand Kit 的《语气与命名》：不把话说满，不催，引号用「」。只讲方法，不推荐具体产品，不写个性化的买卖建议。
- Coin Metrics 社区版只许非商业使用。站点免费，但挂在有付费会员的品牌下，上线前请用户确认是否接受，或换数据源。
- 正文字体 MiSans 没有公共 CDN，访客没装时回退到苹方，和 Long Arc 主站现状一致。
